**OpenClip** — это сверхлегкий, молниеносный и высокозащищенный менеджер буфера обмена, созданный специально для macOS на языке Rust. Наша цель была предельно ясна: **создать идеальную замену CopyClip**, выиграв битву за каждый байт оперативной памяти, при этом сохранив красивый эстетичный дизайн в стиле Apple.

## ⚡ Почему OpenClip? ("Убийца CopyClip")

Большинство современных менеджеров буфера обмена (даже такие популярные, как CopyClip, или написанные на базе тяжелого Electron) потребляют непозволительно много системных ресурсов, "съедая" сотни мегабайт в фоновом режиме.

В OpenClip используется **Микро-сервисная архитектура**:
- Из фонового процесса полностью вырезаны графические движки и 3D-рендеры (Metal), что снижает приватное потребление памяти до абсолютного, математически возможного минимума (около ~15-20 МБ приватной памяти, или ~65 МБ RSS с учетом системных Apple-фреймворков).
- Роскошное окно **Настроек (Preferences)** запускается в виде отдельной программы только тогда, когда оно вам нужно, и полностью завершается при закрытии, мгновенно освобождая графическую память!
- Полностью **Бесплатный и Open Source** (открытый исходный код).

## 🔒 Безопасность военного уровня
Ваш буфер обмена часто содержит самые чувствительные данные: пароли, приватные ключи, крипто-кошельки.

* **AES-256-GCM Шифрование**: Вся ваша история шифруется на диске по военному стандарту. Прочитать этот файл без ключа математически невозможно.
* **Apple Keychain**: Ключ для расшифровки надежно спрятан в системной "Связке ключей" macOS. Никаких паролей в открытом виде!
* **Никакой телеметрии**: OpenClip работает на 100% локально и не обращается к сети интернет.

---

## 💾 Экстремальная оптимизация (LZ4 Сжатие)
OpenClip использует индустриальные стандарты работы с памятью:
- Вместо хранения "сырых" мегабайтов текста в оперативной памяти, программа **сжимает историю "на лету" с помощью сверхбыстрого алгоритма LZ4**.
- В памяти хранится лишь крошечное "превью" из 37 символов для мгновенной отрисовки меню. А огромные "простыни" текста распаковываются за миллисекунды ровно в момент, когда вы нажимаете на них для вставки!

## 🚀 Установка и Сборка

Убедитесь, что у вас установлен язык [Rust](https://rustup.rs/).

```bash
# Клонируйте репозиторий
git clone https://github.com/your-username/OpenClip.git
cd OpenClip

# Соберите и фоновый демон, и окно настроек
cargo build --release

# Готовое приложение будет собрано внутри папки OpenClip.app!
```
